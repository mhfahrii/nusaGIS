# Audit antislop UI/UX — NusaGIS Monitoring & Upload GIS

**Tanggal:** 2026-11-17  
**Scope:** `src/components/gis/monitoring/*` (dashboard, sidebar, upload modal, panel atribut, header)  
**Mode:** AFTER (hanya laporan; belum ada perubahan kode)  
**Design Read (inferensi):** alat operasional GIS internal perkebunan, bahasa Indonesia, ENERGY 2 / RHYTHM 2 / MOTION 1 — **tanpa `DESIGN.md` resmi di repo**

---

## Ringkasan

Antarmuka sudah konsisten (palet gelap + aksen cyan) dan fungsional untuk alur upload/inspect. Pola yang terbaca “AI slop” mainly: **badge dekoratif**, **aksen cyan di mana-mana**, **emoji sebagai ikon**, **em dash di copy**, **focus keyboard hilang**, dan **tidak ada dokumen arah desain**.

---

## Temuan (pilih nomor yang ingin diperbaiki)

| # | Prioritas | Aturan | Temuan |
|---|-----------|--------|--------|
| **1** | HIGH | R-37 | Tidak ada `DESIGN.md` / brief visual; output tidak dilabeli *draft tanpa arah*. Risiko keputusan warna/font hanya mengikuti default “dashboard gelap + cyan”. |
| **2** | HIGH | R-02 | Em dash (`—`) di teks UI pengguna, contoh: opsi kebun di `GisUploadModal`, placeholder insight di `ShapefileInsightPanel`. |
| **3** | HIGH | R-32 | Banyak kontrol pakai `focus:outline-none` tanpa ring pengganti yang jelas (sidebar, upload, header, bottom panel). Tab keyboard sulit dilacak. |
| **4** | MEDIUM | R-09 | Badge kapsul dekoratif tanpa fungsi status nyata: “Standar ArcGIS”, “AKTIF”, “PostGIS”, “ArcGIS” di header/upload — menumpuk nuansa “produk SaaS generik”. |
| **5** | MEDIUM | R-01 + R-13 | Aksen `#00D2FF` dipakai serentak: border fokus, badge, ikon logo, tombol primer, highlight tabel. Satu aksen di banyak lapisan (slop “tech glow”). |
| **6** | MEDIUM | R-04 | Emoji sebagai ikon UI (`📍`, `🌱`, `🌐`, `🏢`, centang silang unicode) menggantikan ikon set yang konsisten (`GisIcons`). |
| **7** | MEDIUM | R-05 + R-16 | Copy berulang “Standar ArcGIS Pro” / “ArcGIS” sebagai dekorasi, bukan penjelasan tindakan. Terasa template marketing, bukan label operasional. |
| **8** | MEDIUM | R-10 | `backdrop-blur` di beberapa modal sekaligus (upload, settings, hapus, create parcel). Glass di banyak permukaan meratakan hierarki. |
| **9** | MEDIUM | R-03 | Banyak kontrol `text-[10px]` / `py-0.5` / `p-1` (toolbar layer, tombol aksi kecil). Target sentuh sering di bawah ~44px di mobile. |
| **10** | LOW | R-11 | Radius bervariasi tanpa sistem jelas (pill badge, `rounded-lg` input, `rounded-xl` kartu) — tidak fatal, tapi terasa “campuran default Tailwind”. |
| **11** | LOW | R-14 | Matriks layer upload: baris seragam (checkbox + input + select + CRS) tanpa variasi hierarki visual antara kolom wajib vs opsional. |
| **12** | LOW | R-27 | Panel atribut punya loading/empty; beberapa subbagian (mis. rename layer) tidak menunjukkan state gagal eksplisit — minor. |
| **13** | LOW | R-21 | Hanya tema gelap, tanpa toggle terang. Untuk GIS lapangan siang hari bisa jadi kebutuhan nyata (bukan slop, tapi gap UX). |

### Catatan positif (bukan temuan)

- Dark default masuk akal untuk monitor peta (kontras peta vs chrome).
- Alur upload 2 langkah (inspect → mapping) **content-driven**, bukan landing template (C-3).
- Tidak terlihat statistik/testimoni palsu di monitoring (R-17, R-18, R-36).
