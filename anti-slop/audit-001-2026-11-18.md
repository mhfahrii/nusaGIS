# Audit Report 001: Frontend Web & GIS Monitoring (`antislop` + `ponytail-audit`)

- **Date:** 2026-11-18
- **Mode:** `antislop` Mode 2 (`AFTER` - Audit first, fix approved items) + `ponytail-audit`
- **Scope:** Entire `src/` frontend (`src/app/**`, `src/components/**`, `src/lib/**`)
- **Direction Selected:** Preserve dark operational GIS identity while refining hierarchy, contrast, layout rhythm, and removing AI slop (`2.A`).

## What this repo does
This web application is an internal plantation spatial monitoring system (GIS Monitoring) built with Next.js, React, Leaflet, and PostgreSQL/PostGIS. Staff upload Shapefile/ZIP/GeoTIFF datasets, digitize plantation blocks, filter by company/region/estate/afdeling, and inspect area audits and harvest projections. Expected load: internal team concurrent usage (10 to 50 active operators inspecting multi-polygon layers up to 50 MB per upload).

## Priority 1: HIGH (Hard Gate `antislop` & Must-Fix `ponytail`)

1. **[HIGH] R-02 (Forbidden Em Dash `—` in UI Text)**
   - **Locations:** `src/app/layout.tsx:5`, `src/components/gis/monitoring/GisUploadModal.tsx:1114`, `src/components/gis/monitoring/MonitoringBottomPanel.tsx:326`, `src/components/gis/monitoring/ShapefileInsightPanel.tsx:419,619,702,741,853`, `src/app/upload/page.tsx:26-32,282`
   - **Reason:** Em dash characters (`—`) appear in the page title, estate dropdown options, empty table cells, and button tooltips.
   - **Fix:** Replace all UI em dashes with colons (`:`), standard hyphens (`-`), commas, or parentheses `()`.

2. **[HIGH] R-25 (WCAG AA Color Contrast Failures on Muted Text & Control Borders)**
   - **Locations:** `src/app/globals.css:16,36`, `src/components/gis/monitoring/MonitoringRightPanel.tsx:287,303,310,331`, `src/components/gis/monitoring/ShapefileInsightPanel.tsx:241,490,853`, `src/components/gis/monitoring/MonitoringBottomPanel.tsx:280,350`
   - **Reason:** Muted text colors `#566680` (3.01:1 on `#12192B`) and `#64748B` (3.68:1 on `#12192B`) fail the WCAG AA 4.5:1 minimum for normal text, and control borders `#1E2942` on `#0D1322` (1.28:1) fail the 3:1 non-text contrast bar.
   - **Fix:** Raise muted text tokens/classes to at least `#8B9BB4` (6.21:1 PASS AA) or `#94A3B8` (6.83:1 PASS AA), and raise interactive control borders (`input`, `select`, `button`) to `#334466` / `#3E547A`.

3. **[HIGH] R-32 & R-39 (Focus Outlines Stripped Without Visible Replacement & Missing Base Affordances)**
   - **Locations:** `src/app/globals.css:1-170`, `src/components/gis/monitoring/MonitoringSidebar.tsx:264,303,327,344,369`, `src/components/gis/monitoring/GisUploadModal.tsx:967,982,1040,1222`, `src/components/gis/monitoring/CreateParcelModal.tsx`
   - **Reason:** Controls use `focus:outline-none` without a high-contrast `:focus-visible` indicator, base CSS lacks centralized `cursor: pointer` / `cursor: not-allowed` rules, and continuous animations in `globals.css` ignore `@media (prefers-reduced-motion: reduce)`.
   - **Fix:** Add base CSS rules in `globals.css` for `:focus-visible` (`2px solid #00D2FF`), `cursor: pointer` on enabled interactive elements, `cursor: not-allowed` on `:disabled`, and `@media (prefers-reduced-motion: reduce)` to disable non-essential motion.

4. **[HIGH] R-32 & R-39 (Icon-Only Controls Missing `aria-label` & Modals Missing Dialog Semantics / `Escape` Close)**
   - **Locations:** `src/components/gis/monitoring/MonitoringSidebar.tsx:191-198,222-229,645-745`, `src/components/gis/monitoring/MonitoringRightPanel.tsx:35-42,79-86`, `src/components/gis/monitoring/GisUploadModal.tsx:554-582`, `src/components/gis/monitoring/SettingsModal.tsx:240-345`, `src/components/gis/monitoring/CreateParcelModal.tsx`
   - **Reason:** Icon-only buttons rely on `title` without `aria-label` (`aria-hidden="true"` on SVGs), and GIS modals (`GisUploadModal`, `CreateParcelModal`, `SettingsModal`, `deleteModal`) lack `role="dialog"`, `aria-modal="true"`, and `Escape` key dismissal.
   - **Fix:** Add `aria-label` to all icon-only buttons, add `role="dialog" aria-modal="true"` to all modal containers, and bind `Escape` to close the active modal.

5. **[HIGH] R-24 & R-26 (Dead Navigation Links `href="#"` & Blocking Browser `alert()` Calls)**
   - **Locations:** `src/components/Sidebar.tsx:34-35,87,118`, `src/components/gis/monitoring/MonitoringDashboard.tsx:558,563,586,591`
   - **Reason:** `Sidebar.tsx` renders `<Link href="#">` for unbuilt pages (*Riwayat Aktivitas*, *Pengaturan*), and `MonitoringDashboard.tsx` uses blocking native `window.alert()` on delete errors.
   - **Fix:** Remove dead `<Link href="#">` anchors in `Sidebar.tsx` (or render non-interactive "Coming soon" rows), and replace `window.alert()` in `MonitoringDashboard.tsx` with a dismissible inline error toast/banner.

6. **[HIGH] R-03 (Mobile & Tablet Viewport Cramping, `100vh` Overflow, and Small Tap Targets)**
   - **Locations:** `src/components/gis/monitoring/MonitoringDashboard.tsx:733`, `src/components/gis/monitoring/MonitoringSidebar.tsx:204`, `src/components/gis/monitoring/MonitoringRightPanel.tsx:86`, `src/components/gis/monitoring/MonitoringHeader.tsx:38`
   - **Reason:** Root container uses `h-screen` instead of `h-dvh`, both sidebars (`w-64`) stay pinned in flex flow on narrow screens squeezing the map canvas, and compact buttons fall below comfortable touch target sizing.
   - **Fix:** Switch root shell to `h-dvh`, make left and right panels slide-over drawers on screens `< 1024px` (auto-collapsed on mobile), and ensure primary interactive controls have adequate hit areas.
